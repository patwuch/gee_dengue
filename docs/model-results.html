Model Results

STGNN (scaledv2) performance on held-out test data (2011–2018)

What is scaledv2?

The scaledv2 experiment introduces seasonal z-score normalisation of the incidence feature before it is passed to the model. A per-month mean (computed over the 2011–2018 training period) is subtracted and the result is divided by the global standard deviation of that de-seasonalised signal. This removes the large seasonal swing that previously dominated the loss, allowing the model to learn from the residual spatial and climate signals instead. A scaler inverse-transform is applied at inference time to recover real-valued incidence rates.

This builds on the baseline_logIR run but with the key difference that input incidence is normalised; all other architecture choices are re-tuned via the same 40-trial Optuna search.

Architecture

The model is a Spatio-Temporal Graph Attention Network with GRU (STGATGRU):

  • Input normalisation: seasonal z-score of incidence (per-month mean removed, divided by global std)
  • GAT layer 1: Spatial message passing over the admin-1 adjacency graph
  • MLP: Node-wise feature transformation
  • GAT layer 2: Second spatial aggregation pass
  • GRU: Temporal sequence modelling over the 12-month sliding window
  • Linear head: Single-step incidence rate prediction (inverse-transformed at output)

Missing admin-1 nodes (no reported incidence) receive a learnable missing embedding rather than zeroed features, and the GRU hidden state is carried over without update for those nodes. Loss masking excludes missing targets from the gradient.

Bias Correction Note

When running inference on current data (post-2018), a climate delta correction is applied before features are passed to the model. The delta is computed as the difference between the AR6 SSP2-4.5 projected monthly climatology for the current year and the 2011–2018 training period climatology. This shifts current observations back into the model’s training feature distribution. See site/scripts/apply_climate_delta.py for implementation.

## Per-Country Metrics

```{python}
#| echo: false
#| label: tbl-country-metrics
#| tbl-cap: "MAE and RMSE broken down by country across the 14 test months."

npz      = np.load(results_dir / "test_predictions.npz")
preds    = npz["predictions"]   # (14, 162)
targets  = npz["targets"]       # (14, 162)

df_csv   = pd.read_csv(data_csv, usecols=["adm_0_name", "adm_1_name"])
nodes    = sorted(df_csv["adm_1_name"].unique())
country  = df_csv.drop_duplicates("adm_1_name").set_index("adm_1_name")["adm_0_name"]

rows_ctry = []
for cname in sorted(df_csv["adm_0_name"].unique()):
    cidx = [i for i, n in enumerate(nodes) if country.get(n) == cname]
    p    = preds[:, cidx].flatten()
    t    = targets[:, cidx].flatten()
    mask = ~(np.isnan(p) | np.isnan(t))
    if mask.sum() == 0:
        continue
    mae  = float(np.mean(np.abs(p[mask] - t[mask])))
    rmse = float(np.sqrt(np.mean((p[mask] - t[mask]) ** 2)))
    rows_ctry.append({"Country": cname, "Nodes": len(cidx), "MAE": mae, "RMSE": rmse})

df_ctry = pd.DataFrame(rows_ctry)
df_ctry["MAE"]  = df_ctry["MAE"].map(lambda v: f"{v:.3f}")
df_ctry["RMSE"] = df_ctry["RMSE"].map(lambda v: f"{v:.3f}")
HTML(df_ctry.to_html(index=False, border=0, classes="table table-sm table-striped"))
```

```{python}
#| echo: false
#| label: fig-interactive-ts
#| fig-cap: "Predicted (dashed) vs actual (solid) IR by admin-1 region. Use the dropdown to filter by country."

df_ts = pd.read_csv(data_csv, usecols=["adm_0_name", "adm_1_name", "year_month", "IR"])
df_ts["year_month"] = pd.to_datetime(df_ts["year_month"])
all_dates = sorted(df_ts["year_month"].unique())
test_dates = all_dates[-14:]

fig2 = go.Figure()
buttons = []
countries_ordered = sorted(df_ts["adm_0_name"].unique())

first_country = True
for cname in countries_ordered:
    cidx   = [i for i, n in enumerate(nodes) if country.get(n) == cname]
    cnodes = [nodes[i] for i in cidx]
    visible_traces = []

    for ni, node in zip(cidx, cnodes):
        node_actual = (
            df_ts[(df_ts["adm_1_name"] == node) & (df_ts["year_month"].isin(test_dates))]
            .set_index("year_month")["IR"]
            .reindex(test_dates)
        )
        node_pred = pd.Series(preds[:, ni], index=test_dates)

        vis = first_country
        fig2.add_trace(go.Scatter(
            x=test_dates, y=node_actual.values,
            mode="lines+markers", name=f"{node} — actual",
            line=dict(width=2), visible=vis,
        ))
        fig2.add_trace(go.Scatter(
            x=test_dates, y=node_pred.values,
            mode="lines+markers", name=f"{node} — pred",
            line=dict(width=2, dash="dash"), visible=vis,
        ))
        visible_traces.append(node)

    first_country = False

# Build visibility arrays for each country button
n_total_traces = len(fig2.data)
trace_offset   = 0
visibility_map = {}
for cname in countries_ordered:
    cidx = [i for i, n in enumerate(nodes) if country.get(n) == cname]
    n_traces_c = len(cidx) * 2
    vis_arr = [False] * n_total_traces
    for j in range(trace_offset, trace_offset + n_traces_c):
        vis_arr[j] = True
    visibility_map[cname] = vis_arr
    trace_offset += n_traces_c

buttons = [
    dict(label=cname,
         method="update",
         args=[{"visible": visibility_map[cname]},
               {"title": f"Predicted vs Actual IR — {cname}"}])
    for cname in countries_ordered
]

fig2.update_layout(
    updatemenus=[dict(
        buttons=buttons,
        direction="down",
        showactive=True,
        x=0.01, xanchor="left",
        y=1.15, yanchor="top",
    )],
    xaxis_title="Month",
    yaxis_title="Incidence Rate (IR)",
    title=f"Predicted vs Actual IR — {countries_ordered[0]}",
    hovermode="x unified",
    legend=dict(orientation="v", x=1.01, y=1),
    margin=dict(l=40, r=180, t=80, b=40),
    height=500,
)
fig2.show()
```

## Architecture

The model is a **Spatio-Temporal Graph Attention Network with GRU** (STGATGRU):

- **Input normalisation:** seasonal z-score of incidence (per-month mean removed, divided by global std)
- **GAT layer 1:** Spatial message passing over the admin-1 adjacency graph
- **MLP:** Node-wise feature transformation
- **GAT layer 2:** Second spatial aggregation pass
- **GRU:** Temporal sequence modelling over the `{python} best_params['window_size']`-month sliding window
- **Linear head:** Single-step incidence rate prediction (inverse-transformed at output)

Missing admin-1 nodes (no reported incidence) receive a learnable missing embedding
rather than zeroed features, and the GRU hidden state is carried over without update
for those nodes.  Loss masking excludes missing targets from the gradient.

## Bias Correction Note

When running inference on current data (post-2018), a climate delta correction is
applied before features are passed to the model.  The delta is computed as the
difference between the AR6 SSP2-4.5 projected monthly climatology for the current
year and the 2011–2018 training period climatology.  This shifts current observations
back into the model's training feature distribution.  See
[site/scripts/apply_climate_delta.py](https://github.com/chuang-lab-DMPTD-TMU/dengue-fever-EWS/blob/main/site/scripts/apply_climate_delta.py)
for implementation.
